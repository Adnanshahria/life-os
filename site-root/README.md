# DeepFocus OS

A static, responsive, and performance-optimized knowledge synthesis platform ("Man-made Second Brain").

## Overview

This project consolidates wisdom from "Atomic Habits", "Deep Work", "The Daily Stoic", and "Dopamine Detox" into a unified "Life Operating System". It features a custom dark mode design ("Black-Grid"), interactive charts, and a responsive structure.

## Structure

*   **/site-root**: The production-ready static site.
    *   `index.html`: The main synthesis dashboard.
    *   `/books`: Specific book summaries and protocols.
    *   `/guides`: Interactive study guides and visual data.
    *   `/protocols`: The Unified Life Protocol.
    *   `/css`: Tailwind-extended custom CSS variables.
    *   `/js`: Client-side logic for search, theme, and mobile menu.

## Features

*   **Black-Grid Design**: A deep-void dark mode optimized for OLED screens and focus.
*   **Client-Side Search**: Instant search across all knowledge bases.
*   **Interactive Visuals**: Chart.js integration for data visualization (Sleep retention, Dopamine levels).
*   **Responsive**: Full mobile support with off-canvas navigation.

## Deployment

Simply host the `site-root` folder on any static hosting provider (Vercel, Netlify, GitHub Pages).

1.  **Vercel**: Drag and drop the `site-root` folder or connect via Git.
2.  **GitHub Pages**: Push the repository and set the source to `site-root` (or root if you move files up).
